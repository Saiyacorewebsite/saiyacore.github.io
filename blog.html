AI & MCP

Release spotlight · Jul 28, 2026

AI agents need more than a prompt. They need a protocol.

The MCP 2026-07-28 specification is a stable release. It provides a shared protocol for connecting AI applications with tools and context.

The practical move

Start with a read-only integration. Review tool permissions and approval boundaries before allowing an agent to change production systems.

Infrastructure as code

Release spotlight · Sep 30, 2026

OpenTofu 1.13: a sharper toolkit for infrastructure teams.

OpenTofu 1.13 adds Windows ARM64 packages and functions that help module authors reduce unknown values during planning. Built-in linting and symbol libraries are experiments.

The practical move

Test existing modules in a sandbox and read the compatibility notes. Keep experimental features out of critical workflows until you have evaluated them.

Observability

Practical explainer · Reviewed Oct 16, 2026

Follow the request. Find the bottleneck.

OpenTelemetry traces show the path of a request across an application. Connected spans make it easier to investigate where work happens across services.

The practical move

Instrument a critical user journey, propagate trace context and connect traces to logs. Review sampling and sensitive attributes before exporting telemetry.

Security release · Oct 14, 2026

Your infrastructure toolchain needs patching, too.

OpenTofu v1.12.8 addresses potential excessive CPU usage when installing dependencies from an attacker-controlled HTTP/2 server during tofu init. It also fixes a lifecycle destroy crash.

The practical move

If you maintain the 1.12 release line, review this patch and your dependency sources. Consult the maintained release line’s notes before choosing an upgrade target.
